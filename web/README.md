# نسخه وب (سمت مرورگر)

این پوشه یک سایت کاملاً استاتیک است — بدون npm، بدون build، بدون سرور. همه‌چیز (پارس متن، ساخت HTML، تم‌ها) داخل مرورگر خودِ کاربر اجرا می‌شود؛ هیچ متنی به هیچ سروری ارسال نمی‌شود.

## ⚠️ نکته مهم برای تست: مستقیم دابل‌کلیک نکنید

اگر `index.html` را مستقیم (با `file://`) در مرورگر باز کنید، فایل‌های جاوااسکریپت داخل `js/` به‌خاطر محدودیت امنیتی مرورگرها روی مسیرهای نسبی لود نمی‌شوند. برای تست، این پوشه را با یک سرور استاتیک ساده اجرا کنید:

```bash
cd web
python3 -m http.server 8000
```

سپس در مرورگر به آدرس زیر بروید:

```
http://localhost:8000
```

(هر ابزار دیگری هم که یک فایل استاتیک سرو کند کار می‌کند — مثلاً `npx serve` یا افزونه‌ی Live Server در VS Code.)

## نحوه تست

1. عنوان/نویسنده/تاریخ را پر کنید (اختیاری).
2. نوع محتوا را انتخاب کنید: «یادداشت ساده» (هیوریستیک فارسی: سرتیتر عددی، `الف)`، `💡`) یا «مارک‌داون کامل» (استاندارد #, **, لیست، جدول، بلاک کد، لینک، تصویر و...).
3. متن را بچسبانید یا یک فایل `.txt`/`.md` را روی کادر بکشید و رها کنید — با فایل `.md` نوع محتوا خودکار روی «مارک‌داون کامل» تنظیم می‌شود.
4. روی «تولید صفحه مطالعه» بزنید؛ همان‌جا در یک پیش‌نمایش زنده (iframe) نتیجه را می‌بینید — تم روشن/سپیا/شب، کنترل فونت و نوار پیشرفت مطالعه همه فعال هستند.
5. با «دانلود HTML مستقل» می‌توانید همان صفحه را به‌صورت یک فایل HTML تکی ذخیره کنید (دقیقاً مثل خروجی نسخه‌ی پایتونی).

## نسبت با نسخه CLI/پایتون

این نسخه‌ی وب **مستقل** از پکیج پایتونی (`src/article_reader/`) است — منطق پارس در `web/js/*.js` با جاوااسکریپت خالص (به‌علاوه‌ی کتابخانه‌ی `markdown-it` از CDN برای حالت «مارک‌داون کامل») بازنویسی شده، چون GitHub Pages فقط فایل استاتیک سرو می‌کند و کد پایتون در آن اجرا نمی‌شود. دو ابزار همان تجربه‌ی کاربری و ظاهر را دارند ولی هر کدام پیاده‌سازی جدای خودشان را دارند.

## استقرار روی GitHub Pages (بعداً)

وقتی مخزن را به گیت‌هاب وصل کردی، کافیست در تنظیمات مخزن، بخش Pages، منبع را روی این پوشه (`/web`) تنظیم کنی — بدون نیاز به هیچ مرحله‌ی build.
