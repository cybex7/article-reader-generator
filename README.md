# Article Reader Generator 📖✨

*[English version](README.en.md)*

مبدل خودکار متن و یادداشت‌ها به صفحات وب مستقل (`.html`) با حداکثر ارگونومی و اصول تجربه کاربری خوانایی متون فارسی.

## 🧭 کدام نسخه را استفاده کنم؟

این مخزن **دو نسخه‌ی مستقل و کاملاً قابل‌استفاده** دارد که هر دو یک ظاهر و تجربه‌ی خواندن یکسان تولید می‌کنند، فقط محل اجراشان فرق دارد:

| | 🐍 نسخه پایتونی (`src/`) | 🌐 نسخه وب استاتیک (`web/`) |
| :--- | :--- | :--- |
| **کجا اجرا می‌شود** | روی سیستم خودت (CLI یا سرور محلی) | داخل مرورگر — قابل میزبانی روی GitHub Pages / Cloudflare Pages |
| **نصب لازم** | پایتون ۳.۱۰+ (`pip install -e .`) | هیچ — فقط باز کردن یک صفحه‌ی HTML |
| **مناسب برای** | استفاده‌ی روزمره‌ی شخصی، پردازش فایل از خط فرمان، اسکریپت/اتوماسیون | ساخت یک ابزار وب که هرکسی (حتی بدون پایتون) از هر مرورگری استفاده کند |
| **دریافت خودکار از آدرس وب** | ✅ داخلی و آماده (`--url`، با `trafilatura`) | نیاز به یک Worker جداگانه دارد (به‌خاطر CORS) — آماده در [`cloudflare-worker/`](cloudflare-worker/) |
| **راهنمای کامل** | بخش «💻 نحوه استفاده» پایین همین فایل | [web/README.md](web/README.md) |

اگر مطمئن نیستی: برای استفاده‌ی شخصی روی سیستم خودت، نسخه‌ی پایتونی ساده‌تره؛ اگر می‌خوای این ابزار رو به‌عنوان یک صفحه‌ی وب در اختیار دیگران (یا خودت از هر دستگاهی) بذاری، نسخه‌ی `web/` رو انتخاب کن.

## 🌟 ویژگی‌های کلیدی

- **عرض بهینه خوانش (Optimal Line-Length):** تنظیم عرض ستون متن روی حداکثر ۷۴۰ پیکسل (حدود ۶۰ تا ۷۵ نویسه در هر خط) برای جلوگیری از خستگی و پرش چشم.
- **تایپوگرافی اختصاصی فارسی:** پیاده‌سازی فونت استاندارد و خوانای **وزیرمتن (Vazirmatn)** با ارتفاع سطر استاندارد (`line-height: 2.18`).
- **پشتیبانی کامل از Markdown:** برای فایل‌های `.md`/`.markdown` (یا محتوای دریافت‌شده از وب)، تمام نشانه‌گذاری‌های استاندارد پردازش می‌شود: سرتیتر، بولد/ایتالیک، لیست تودرتو، نقل‌قول، لینک، تصویر، جدول و بلاک کد. برای یادداشت‌های ساده همان هیوریستیک سبک قبلی (سرتیتر عددی، `الف)`، `💡`) به‌کار می‌رود؛ انتخاب حالت خودکار (بر اساس پسوند فایل) یا دستی است.
- **فهرست مطالب خودکار:** ساخت خودکار فهرست مطالب قابل جمع‌شدن، از روی سرتیترهای عددی (حالت ساده) یا تمام سطوح سرتیتر با تورفتگی (حالت Markdown).
- **تم‌های مطالعه سه‌گانه:**
  - **روشن (Light):** کنتراست متعادل با پس‌زمینه ملایم بدون نور خیره‌کننده.
  - **سپیا (Sepia):** شبیه‌ساز کاغذ کتاب و مناسب برای مطالعه طولانی.
  - **شب (Dark):** پس‌زمینه تیره ملایم برای محیط‌های کم‌نور.
- **کنترل اندازه قلم (Font Sizer):** امکان بزرگ‌نمایی و کوچک‌نمایی متن با یک کلیک بدون برهم‌ریختگی کادرها.
- **نوار پیشرفت لحظه‌ای (Reading Progress Bar):** نمایش درصد مطالعه شده مقاله در بالای صفحه.
- **محاسبه هوشمند زمان مطالعه:** برآورد زمان پایان بر اساس ۲۰۰ کلمه در دقیقه.
- **آپلود با درگ‌اند‌دراپ:** در رابط وب می‌توانید فایل TXT/MD را مستقیم بکشید و رها کنید، یا کلیک کرده و انتخاب کنید.
- **دریافت مستقیم از آدرس وب:** فقط لینک یک مقاله را بده تا متن اصلی آن (بدون منو، تبلیغ و سایدبار) به‌طور خودکار استخراج شود (با `trafilatura`).
- **خروجی مستقل:** خروجی نهایی یک تک‌فایل HTML با CDN است که برای *باز کردن* نیازمند هیچ ابزار یا فریم‌ورک جانبی نیست (هرچند خودِ ابزار تولیدکننده یک وابستگی پایتونی دارد).
- **دو حالت استفاده:** هم به صورت دستور ترمینال (CLI) و هم رابط گرافیکی تحت وب محلی (`Web UI`).

## 💻 نحوه استفاده

### ۱. اجرای رابط وب محلی (ساده‌ترین روش)

```bash
article-reader --serve
```

سپس مرورگر خود را باز کرده و وارد آدرس `http://localhost:8080` شوید. متن خود را در فرم قرار دهید یا فایل را درگ‌اند‌دراپ کنید و با کلیک روی دکمه، فایل HTML اختصاصی خود را دریافت کنید.

---

### ۲. اجرا از طریق خط فرمان (CLI)

```bash
article-reader examples/sample_article.txt \
  --title "مبانی جامعه‌شناسی" \
  --author "امین بزرگیان" \
  --date "جلسه اول - ۰۵/۰۵/۲۱" \
  -o sociology_lesson1.html
```

یا مستقیم از روی یک آدرس وب:

```bash
article-reader --url "https://example.com/some-article" -o article.html
```

#### پارامترهای دردسترس:
| پارامتر | توضیح |
| :--- | :--- |
| `input` | فایل ورودی متنی یا مارک‌داون |
| `-u`, `--url` | آدرس صفحه وب برای دریافت و استخراج خودکار متن مقاله (به‌جای فایل ورودی) |
| `-o`, `--output` | نام فایل خروجی HTML (پیش‌فرض: هم‌نام با فایل ورودی، یا برگرفته از عنوان در حالت `--url`) |
| `-t`, `--title` | عنوان اصلی مقاله (در حالت `--url` در صورت خالی بودن، از صفحه استخراج می‌شود) |
| `-a`, `--author` | نام نویسنده یا ارائه‌دهنده |
| `-d`, `--date` | تاریخ یا برچسب جلسه |
| `-f`, `--format` | نحوه پردازش متن: `auto` (پیش‌فرض، بر اساس پسوند فایل/آدرس وب)، `plain` یا `markdown` |
| `--serve` | فعال‌سازی وب‌سرور داخلی با رابط کاربری (شامل فیلد دریافت از آدرس وب) |
| `--port` | تعیین پورت سرور (پیش‌فرض: 8080) |

## 🌐 نسخه وب (سمت مرورگر، آماده GitHub Pages)

پوشه‌ی [`web/`](web/) یک نسخه‌ی کاملاً مستقل و استاتیک است که بدون سرور، فقط داخل مرورگر اجرا می‌شود (پشتیبانی کامل از Markdown با `markdown-it`). راهنمای تست محلی در [web/README.md](web/README.md).

برای دریافت خودکار از آدرس وب در همین نسخه، [`cloudflare-worker/`](cloudflare-worker/) یک Worker مستقل (JS، با Readability موزیلا) است که مشکل CORS یک سایت استاتیک را حل می‌کند — جزئیات در [cloudflare-worker/README.md](cloudflare-worker/README.md).
